# PDQ Planner for Mac

Downloads and updates for the PDQ Planner Mac app. This repository holds release files only; it contains no source code.

## Install

1. Open the [latest release](https://github.com/fusionnest-ca/pdq-planner-releases/releases/latest) and download the `.dmg`.
2. Open it and drag **PDQ Planner** into Applications.
3. The first time, right-click the app in Applications and choose **Open**.

## Updates

Installed copies update themselves. The app checks for new versions shortly after it opens and every few hours. To check now, choose **PDQ Planner › Check for Updates…**
